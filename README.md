# Pure Honey — A 3D Journey into the Hive

## Overview (English)

A **single-file code snippet** for e-commerce websites — as you scroll, the viewer **flies out of the hive as a bee** and enters a cinematic journey through single-origin honeys. Pure HTML/CSS/JS, no heavy libraries. Matches the current trend of scroll-driven 3D sites.

### Features

- 🐝 Scroll-driven cinematic bee journey out of the hive
- 🍯 Four single-origin honeys (Thyme, Sour Orange, Astragalus, Ziziphus) with real photos
- 📱 Mobile-friendly (viewport-fit=cover)
- 🚀 Single file, zero dependencies — just open `index.html`
- 🌐 Ready for GitHub Pages (`CNAME` included)

### Run

Open `index.html` in a browser. That's it!
